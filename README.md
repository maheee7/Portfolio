# Mahendran S. | Personal Portfolio

A premium, modern personal portfolio built with **Next.js**, **Tailwind CSS**, and **Framer Motion**. This project showcases my professional journey, technical expertise, and a curated selection of my finest work.

![Portfolio Preview](/public/hero-bg.png) <!-- Note: Replace with actual screenshot path if available -->

## ✨ Features

-   **Dynamic Hero Section**: Engaging introduction with smooth animations.
-   **Interactive Projects Showcase**: Detailed views of key projects with tech stack highlights.
-   **Work Experience Timeline**: A professional history of my roles and contributions.
-   **Responsive Design**: Fully optimized for all screen sizes (Mobile, Tablet, Desktop).
-   **Dark/Light Mode**: Seamless theme switching using `next-themes`.
-   **Performance Optimized**: Leveraging Next.js 15+ features for speed and SEO.
-   **Contact Interface**: Ready-to-use contact form for professional inquiries.

## 🛠️ Tech Stack

-   **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
-   **Animations**: [Framer Motion](https://www.framer.com/motion/)
-   **Icons**: [Lucide React](https://lucide.dev/)
-   **UI Components**: Custom components with `clsx` and `tailwind-merge`

## 🚀 Getting Started

### Prerequisites

-   Node.js 18+ 
-   npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/your-username/personal-portfolio.git
    cd personal-portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
